# IBM Data Science Capstone

## SpaceX Launch Site Analysis with Folium

This project analyzes SpaceX launch sites using interactive maps built with Folium and Python.

## Technologies Used
- Python
- Pandas
- Folium
- Jupyter Notebook

## Project Objectives
- Visualize SpaceX launch site locations
- Analyze launch success and failure patterns
- Calculate distances to coastlines, railways, highways, and cities
- Explore geographical factors affecting launch operations

## Key Findings
- Launch sites are generally located near coastlines.
- Launch sites are connected to transportation infrastructure.
- Launch sites maintain a safe distance from major cities.
